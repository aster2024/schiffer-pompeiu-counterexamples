# R⁶ 中的 Schiffer / Pompeiu 反例：O(3)×O(3) 子午面构造

**状态（2026-09-28，发布版）：本地计算机辅助证明通过；`Ω` 还是凸的（§9）。** `verify_r6.py --stage final` 在 128 位 Arb 球算术下，核对冻结中心、近似逆、所有有限列与无穷尾界、四次半径多项式及几何条件后输出 `PROVED`；完整数值收据在 `certificate_r6.json`。这是可复算的本地证明包，尚未经过独立同行审核。复算脚本 `reproduce_r6.sh` 会重新生成七份区间收据并逐字节核对。以下给出数学论证和各数值门槛，说明程序中的每项检查为何足以证明结论。

## 1. 定理与中心

**定理。** 存在有界、严格星形的实解析区域 `Ω ⊂ R³×R³ = R⁶`，其边界实解析且微分同胚于 `S⁵`，`Ω` 不是球；还存在非常数实解析函数 `u`，在 `Ω̄` 的一个邻域上定义，并满足

```text
Δ₆u + u = 0       于 Ω，
u = 1，∇u = 0      于 ∂Ω。
```

`Ω` 对两组各自的 `O(3)` 旋转、两组交换保持不变。由 Green 恒等式，`χ_Ω` 的 Fourier 变换在单位频率球面上恒为零，因此 `Ω` 也不具有 Pompeiu 性质。

构造在共形归一化 `μ=1` 下进行。冻结中心的映射为

```text
ψ°(w)=Σ_{j=1 (mod 4), j≤57} c°_j w^j,
c°₁=28.864750643300045,
c°₅=−0.08529699368630728,
c°₉=−0.08377344149934289。
```

中心还有 450 个圆盘多项式系数 `g°_{n,s}`（`n=2,6,…,58`；`s=1,…,30`），全部作为精确二进制有理数存于 `center_r6.json`。真实解与此中心在下述 Banach 范数中的距离不超过 `r=1/5000`。中心来自 `ρ=j_{3,8}=28.908350780921758` 附近的 Bessel 配置解；这里 `ρ` 是用于寻找中心的**单位球波数**，与证明中固定的系数权 `ρ_w=11/10` 不同。

## 2. 六维问题精确化为平面问题

记 `y₁=|x'|`、`y₂=|x''|`。若 `u=u(y₁,y₂)` 对两组 `O(3)` 不变，则在 `y₁y₂>0` 处

```text
Δ₆u = u₁₁ + (2/y₁)u₁ + u₂₂ + (2/y₂)u₂，
Δ₂(y₁y₂u)=y₁y₂ Δ₆u。                                  (2.1)
```

第二式直接由两次乘积求导得到，并由 `symbolic_reduction.py` 作了精确符号核对。令 `F=y₁y₂u`。六维 Cauchy 边界条件变为子午面区域 `D` 上的

```text
(Δ₂+1)F=0，  F=y₁y₂，  ∇F=(y₂,y₁)  于 ∂D。             (2.2)
```

`F` 分别关于 `y₁`、`y₂` 为奇函数；关于两坐标交换为偶函数。若 `F` 在对称轴的邻域内实解析，则其双重奇 Taylor 级数可逐项提出 `y₁y₂`，得到 `F=y₁y₂G(y₁²,y₂²)`，故 `u(x',x'')=G(|x'|²,|x''|²)` 解析地穿过两条轴。这个论证同时适用于两轴交点。

取全纯映射

```text
ψ(w)=Σ_{j≡1 (mod 4)} c_j w^j， c_j∈R， c₁>0， D=ψ(𝔻)。
```

它满足 `ψ(\bar w)=\overline{ψ(w)}` 与 `ψ(iw)=iψ(w)`，从而给出所需的两轴反射及交换对称。令 `h_ψ=Im(ψ²)/2`；这正是 `(y₁y₂)∘ψ`。若 `V=F∘ψ`，平面 Laplacian 的共形协变性把 (2.2) 变为

```text
ΔV+|ψ'|²V=0 于 𝔻，
V−h_ψ=0，∂ᵣ(V−h_ψ)=0 于 ∂𝔻。                             (2.3)
```

圆周上的零 Dirichlet 迹还使切向导数为零，因此两个迹等价于物理平面中的完整梯度条件。

## 3. 圆盘系数方程及函数空间

用归一化圆盘多项式

```text
S_{n,s}(r,θ)=rⁿ P_s^(0,n)(2r²−1) sin(nθ)，
n≡2 (mod 4)， n≥2，s≥0，P_s^(0,n)(1)=1。
```

此扇区恰是关于两轴奇、关于交换偶的函数空间。`|ψ'|²` 属于角频率 `4k` 的偶扇区，因此乘积仍在这个正弦扇区。设 `G` 是没有 `s=0` 系数的子空间。双迹零的 Poisson 逆 `K:G→G` 的像满足

```text
K S_{n,s}=
  S_{n,s−1}/[4d(d+1)] − S_{n,s}/[2d(d+2)]
  + S_{n,s+1}/[4(d+1)(d+2)]， d=n+2s，s≥1。              (3.1)
```

由 Jacobi 递推直接得 `ΔKf=f` 且 `Kf=∂ᵣKf=0` 于圆周。其列系数绝对值之和为 `1/[d(d+2)]`，本扇区 `d≥4`，故 `‖K‖≤1/24`。圆盘多项式正线性化使全角频率加权 `ℓ¹` 范数成为常数 1 的 Banach 代数；这些为 Colbrook–Stepaniants 的圆盘多项式引理（也列于 `../the four-dimensional construction/PROOF.md` §4）。它们适用于任意整数角频率，故取本扇区不改变证明。

令 `W=V−h_ψ=Kg`。应求的零点为

```text
H(g,c)=g+|ψ'_c|²(Kg+h_c)=0， h_c=Im(ψ_c²)/2。          (3.2)
```

`H=0` 立即推出 (2.3)。固定 `ρ_w=11/10`，记 `b=c°₁`、`α=b³/2`，赋予

```text
‖g‖_G=Σ_{n≡2(4),s≥1} ρ_wⁿ |g_{n,s}|，
ω_j=α(j+2)ρ_w^{j+1}，
‖c‖_C=Σ_{j≡1(4)} ω_j |c_j|，
‖(g,c)‖_X=‖g‖_G+‖c‖_C。
```

有 `N(η)≤θ₀‖η‖_C`、`N(η')≤θ₁‖η‖_C`，其中全纯系数范数 `N` 也按 `ρ_w` 加权，且

```text
θ₀=1/(3αρ_w)， θ₁=1/(αρ_w²)。
```

故 (3.2) 是 `X→` 正弦扇区的连续四次多项式映射。

## 4. 近球种子与独立数值核对

在 `S⁵` 的 `O(3)×O(3)` 不变类中，置 `t=cos(2θ)` 后测度为常数倍 `√(1−t²)dt`，角谐函数为 `Y_j=U_j(t)/(j+1)`，六维球谐次数 `ℓ=2j`。交换两组要求 `j` 为偶数。Chebyshev-U 乘积公式给出 `U_j²=Σ_{k=0}^j U_{2k}`，于是对偶数 `j`，

```text
⟨Y_j³⟩/⟨Y_j²⟩=1/(j+1)≠0。                           (4.1)
```

`symbolic_reduction.py` 用精确多项式矩对 `j=2,4,6,8` 核对了 (4.1)。径向 Neumann 球根是 `J₃(ρ)=0`，非径向 Dirichlet 小除数为 `J_{ℓ+2}(ρ)`。`scan_r6.py` 找到 `m=8,ℓ=8`：`J₁₀(ρ)=−0.003015284611…`，二阶振幅预测 `b_8≈0.00727006`。

独立的 `r6_bessel.py` 把 `u` 展开成正则六维球 Bessel 模 `r^{-2}J_{ℓ+2}(ρr)Y_{ℓ/2}`，用径向图同时配置 `u=1`、`u_r=0`。20 模解有 `b_8=0.00718409169098076`，2001 点离网格 Cauchy 缺陷分别为 `8.22×10⁻¹⁴` 与 `2.17×10⁻¹³`；28 模双精度解一致。`pompeiu_r6.py` 仅取其边界，独立计算 14 个体积分矩，相对缺陷为 `0` 至 `3.3×10⁻¹³`，单模对照形状的低阶缺陷达 `4.74×10⁻³`。这些只用于找中心，不进入存在性证明。

`from_bessel_r6.py` 用 Theodorsen 共形参数化得到 `c°` 与 `g°`；(3.2) 的全部有限及尾系数随后由 `verify_r6.py` 的精确圆盘多项式运算重新计算，不依赖配置残差。

## 5. 近似逆与全部无穷尾

有限块取 `M=58,S=30`：450 个 `g_{n,s}` 列、15 个 `c_j` 列；行是对应 450 个非调和行和 15 个 `s=0` 调和行。`inverse_r6_M58_S30.npy` 给定一个**固定的二进制有理近似逆** `Â`。`finite_interval_r6.py` 对有限 Jacobian 每个系数作 Arb 计算，证明加权 `‖I−ÂM_f‖<6.714×10⁻¹¹<1`；因此 `Â` 本身可逆，未把浮点求逆当作证明。

形状尾的主算子可以完全写出。对 `j≡1 (mod 4)`，在 `ψ=bw`、`h=b²r²sin2θ/2` 处把 `DH` 的 `h` 部分作用于 `w^j`，得到

```text
T_j= b³{(j+2)S_{j+1,0}/2 − (j−2)S_{j−3,0}/2
          − jS_{j−3,1}/(j+1) − S_{j−3,2}/(j+1)}。      (5.1)
```

这里唯一需要的径向展开是 `r^{m+4}sin(mθ)=(m+1)S_{m,0}/(m+3)+2S_{m,1}/(m+4)+2S_{m,2}/[(m+3)(m+4)]`。`check_tail_r6.py` 用有理数检验此式以及 (5.1)，并把 (5.1) 与完整 Jacobian 的球形特例逐系数比较。

调和尾行 `n≡2 (mod 4)` 因而是差分

```text
y_{n,0}=α(n+1)(η_{n−1}−η_{n+3})，
η_{n−1}=Σ_{k≥0} y_{n+4k,0}/[α(n+4k+1)]。             (5.2)
```

非调和尾行以 (5.1) 的 `s=1,2` 系数作相应修正；第一个形状尾列 `j=61` 对有限行 `n=58` 的耦合也精确保留。以 (5.2) 的尾逆及有限逆 `Â` 组成上三角算子 `A`，则 `A` 可逆。`tail_inverse_r6.py` 对调和输入 `n=62,…,458` 逐列作 Arb 检查，再用几何级数 `1/(1−ρ_w^{-4})` 处理更远输入，得到

```text
‖A‖_finite < 1402.314，  ‖A‖_tail < 3.164016。    (5.3)
```

残差与导数缺陷的列分类如下；所有表中上界均为 Arb **上端点**，不是中点：

| 类别 | 覆盖范围与方法 | 上界 |
|---|---:|---:|
| `Y=‖AH(x°)‖` | 完整系数残差 | `5.243310×10⁻⁵` |
| `Z_fin` | 465 个有限列逐列 | `0.073227` |
| `Z_g_near` | 705 个尾 `g` 列逐列 | `0.313291` |
| `Z_g_far` | 高角频率或高径向指标解析界 | `0.390424` |
| `Z_shape_near` | `j=61,65,…,397` 共 85 列 | `0.387180` |
| `Z_shape_far` | `j≥401` 解析界 | `0.464977` |

`g` 尾按 `p=ψ'` 的次数 24 分短项：`P_s=Σ_{a≤24}|p_a|ρ_w^a`、`P_t=Σ_{a>24}|p_a|ρ_w^a`，且 `δ_a=2P_sP_t+P_t²<0.016667`。每个短项近尾列完整展开；长项由 `‖A‖δ_a/[d(d+2)]` 控制。若角频率 `n≥86`，短项输出只有尾行，故可用 `‖A‖_tail`；若径向指标 `s≥56`，短项输出的径向指标大于 30，`A` 在该部分为恒等。其余恰为已核对的 705 列。这里所用支持下界 `s'≥s−max(a,b)` 来自圆盘多项式与 `w^a\bar w^b` 相乘时的 Jacobi 正交性（见 `../the four-dimensional construction/PROOF.md` 引理 7.1）。

远形状尾需要利用双迹零造成的二阶边界因子，不能直接用 `‖Kg°‖`。由 (3.1) 与 Jacobi 正交性，

```text
K S_{n,s}=(1−r²)² rⁿP_{s−1}^{(2,n)}(2r²−1)sin(nθ)/[4s(s+1)]。
```

记 `Kg°=(1−r²)²Q`。`far_shape_r6.py` 以正的 Jacobi 连接系数构造 `Q`；独立 Arb 恒等检查给出的两种展开加权差小于 `4.8×10⁻⁴¹`。置 `h₀=b²r²sin2θ/2`、`a=|ψ'|²`，把 `DH(w^j)−T_j` 的非 `Kg` 部分写成

```text
2·antisym { j w^{j−1} Γ₁ − w^j Γ₀/2 }，
Γ₁=\bar ψ' h_ψ−b h₀， Γ₀=aψ−b³w。
```

这里 `antisym` 是从全 Fourier–Zernike 系数到正弦系数的范数不增投影。程序给出 `‖Γ₁‖=844.817923…`、`‖Γ₀‖=4110.324378…`。再取 `L=M+max deg(ψ')=114`，使 `w^L\bar ψ'Q` 的所有频率非负。圆盘多项式的高频乘积界是

```text
‖(1−r²)² w^N Z‖ ≤ Σ_{m,t} 4(2t+1)(2t+3)
                       |Z_{m,t}|ρ_w^{m+N}/(m+N+1)²。
```

其证明连续两次应用 `(1−r²)` 的 Jacobi 三项式，每次的系数绝对值和不超过 `2(2t+1)/(m+N+1)`。当 `j≥401` 时，非主部所有频率至少为 `j−171≥230>M`，可乘 (5.3) 的**尾部**范数而无需 `1402.314`。此时 `Γ` 部分相对形状权的界是 `0.11689839`，`Kg` 部分是 `0.03005935`，合并得到 `Z_shape_far<0.464977`。这是所有导数列中最大的上界。

## 6. 半径多项式与真实解

令 `P=N(ψ°')`、`C=N(ψ°)`、`V°=Kg°+h°`，`κ=1/24`。以 `a=‖δg‖_G`、`e=‖η‖_C` 计，(3.2) 的二、三、四次余项分别由

```text
B₂ ≤ 2Pθ₁κ·ea
   + (2Pθ₁Cθ₀ + P²θ₀²/2 + θ₁²‖V°‖)e²，
B₃ ≤ θ₁²κ·e²a + (Pθ₁θ₀²+θ₁²Cθ₀)e³，
B₄ ≤ θ₁²θ₀²e⁴/2。
```

这是把 `|ψ'+η'|²` 与 `Im(ψ+η)²/2` 精确展开后逐项用 Banach 代数界所得。乘 (5.3) 的全算子界得到

```text
C₂<0.250135， C₃<2.761×10⁻⁷， C₄<2.104×10⁻¹⁵。
```

验证器只用更大的**有理数门槛** `Y_q=53/10⁶`、`Z_q=47/100`、`C₂q=251/1000`、`C₃q=3/10⁷`、`C₄q=3/10¹⁵`、`r=1/5000`。对 `T(x)=x−AH(x)`，

```text
Y_q+(Z_q−1)r+C₂q r²+C₃q r³+C₄q r⁴
    = −5.29899599999976×10⁻⁵ < 0，
Z_q−1+2C₂q r+3C₃q r²+4C₄q r³
    = −0.529899599999964 < 0。
```

因此 `T` 把 `B_X(x°,r)` 严格映入自身且为收缩；Banach 不动点定理给唯一 `x*`。`A` 可逆，故 `H(x*)=0`，即 (2.3) 有精确解。`verify_r6.py` 对每项区间比较均 fail-closed；任何缺失批次、改变的冻结输入、非有限区间或不通过的几何门槛都不会打印 `PROVED`。

## 7. 解析边界、双轴重建与非球性

由 `‖x*−x°‖_X≤r` 可逐系数控制映射。验证器在 `|w|≤21/20` 上得到

```text
c*₁ − Σ_{j≥5}j|c*_j|(21/20)^{j−1} > 27.2138856，
sup_|w|=1 |wψ*'(w)/ψ*(w)−1| < 0.063445，
|c*₅|>0.08529699。
```

第一式使 `Re ψ*'>0` 于稍大于闭单位盘的凸盘上，故沿任意两点间线段积分可证 `ψ*` 单叶并解析延拓；第二式使圆周映像的极角严格递增，故 `D=ψ*(𝔻)` 严格星形；第三式使 `D` 不是圆盘。`ψ*` 与 `h*` 解析，(2.3) 是解析系数椭圆方程且有解析双 Cauchy 数据。局部解析 Cauchy 定理及内部唯一性使 `V*`（从而 `F*`）实解析地延拓过 `∂D`。

把 `D` 的极径写作 `R(θ)`。两轴反射和交换给出其 `cos(4kθ)` Fourier 展开；由于边界解析，这些系数指数衰减。`cos(4kθ)=T_{2k}(cos2θ)`，而在 `S⁵` 上 `cos2θ=|ω'|²−|ω''|²` 是实解析函数。因此 `R` 诱导 `S⁵` 上的正解析函数，映射 `ω↦R(ω)ω` 是 `∂Ω` 的解析嵌入，`Ω` 有界、严格星形且 `∂Ω≅S⁵`。`F*` 双轴奇性与 §2 的解析除法给出 `u` 在两轴及其交点的解析延拓。由 (2.1) 和连续性得六维 PDE；由 (2.2) 和连续性得 `u=1`、`∇u=0` 于整个边界。常数 `u≡1` 不满足 `Δu+u=0`，所以 `u` 非常数。

如果 `Ω` 是球，对称性迫使球心为 0，子午面 `D` 就是圆盘。把 0 映到 0、导数正实的共形映射只能是线性 `ψ(w)=c₁w`，与 `|c*₅|>0` 矛盾。最后，对任意 `|ξ|=1`，令 `v=e^{iξ·x}` 并对 `u,v` 用 Green 第二恒等式；两者满足同一 Helmholtz 方程，边界数据给 `∫_{∂Ω}∂_νv=0`，散度定理给 `−∫_Ωv=0`。这证明 Pompeiu 结论。
